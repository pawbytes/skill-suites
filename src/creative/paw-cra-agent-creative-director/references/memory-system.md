# Memory System

Aria keeps the agency's files in `{suite-root}/` (normally `{project-root}/paw-suites/creative/`). Other specialists read from and write to this same tree. Memory lives in `_memory/`; deliverables live with their brand, never in `_memory/`.

## Core Principle

Memory enables continuity. A brand onboarded today should inform work next month. A campaign brief should be retrievable by any specialist. Memory persists across sessions.

## File Structure

```
{suite-root}/
├── README.md                 # suite index, generated by `paw-paths.py index`
├── _memory/
│   ├── index.md              # entry point: active brand, current campaigns, tool status
│   ├── tool-status.md
│   ├── daily/{YYYY-MM-DD}.md # daily logs
│   └── knowledge/            # researched specs and guides (index.md)
├── templates/                # reusable design templates
└── brands/{brand}/
    ├── README.md             # brand dashboard: Status:, Next:, key links
    ├── profile.md
    ├── guidelines.md
    ├── research/             # Strategist reports, screenshots/
    ├── brand-assets/         # logo/, icons/, banners/, avatars/, video/ (intros, watermarks)
    ├── briefs/{name}.md      # standalone briefs, not yet campaigns
    ├── campaigns/YYYY-MM-<campaign>/
    │   ├── brief.md  plan.md  status.md  content-calendar.md  qa-report.md
    │   ├── copy/  scripts/
    │   ├── designs/          # social/, carousels/, flyers/, resized/, batch-{date}/
    │   ├── videos/           # short-form/, long-form/, clips/, audio/, series/{name}/
    │   └── exports/          # platform variants
    ├── designs/              # non-campaign graphics: social/, carousels/, flyers/, resized/, wip/
    ├── videos/               # non-campaign video: short-form/, long-form/{slug}/, clips/{session}/,
    │                         # motion-graphics/, series/{name}/, audio/, .work/
    └── exports/
```

Work without a brand goes under `brands/unassigned/`. Browser sessions are secrets and stay hidden in `{project-root}/.pawbytes/creative/.auth/`.

## Write Discipline

- **Always append, never overwrite** — preserve history
- **Use timestamps** — `## 2026-03-31 14:32` format for entries
- **Cross-reference** — link to related files when relevant
- **Keep index current** — update active brand and campaigns in `_memory/index.md`; keep each brand's `README.md` `Status:`/`Next:` lines current and run `uv run {skill-root}/scripts/paw-paths.py index` after changing them

## Index Format

```markdown
# Creative Suites Index

## Tool Status
- fal: available
- elevenlabs: unavailable
- pexels: available
- ffmpeg: available

## Active Brand
{brand-name}

## Active Campaigns
- {campaign-name}: in_progress
- {campaign-name}: blocked

## Recent Activity
- 2026-03-31: Onboarded brand "Acme Co"
- 2026-03-30: Completed campaign "Spring Launch"
```

## Memory Maintenance

- **Daily logs** — brief summary of what happened each session
- **Archive completed campaigns** — move to `brands/{brand}/campaigns/_archived/` after delivery
- **Prune old daily logs** — keep last 30 days, archive older

## Initialization

If memory doesn't exist, run `uv run {skill-root}/scripts/init-memory.py {project-root}` to create the structure. Then guide the user through brand onboarding.
