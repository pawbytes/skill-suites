# Brand Directory Structure

This reference defines the standard directory layout for brand workspaces. Create this structure during new brand onboarding.

`{suite-root}` is `root` from `paw-paths.py detect`, normally `{project-root}/paw-suites/marketing`. In legacy mode pass each path through `paw-paths.py locate` (see SKILL.md).

---

## Full Structure

```
{suite-root}/
  README.md                           # Suite index, generated by `paw-paths.py index`
  reports/                            # Cross-brand reports (config mkt.reports_folder)
  dashboards/launcher.html            # Multi-brand dashboard launcher (paw-mkt-dashboard)
  brands/{brand-slug}/
    README.md                         # Brand dashboard: Status:, Next:, key file links
    brand-context.md                  # Core brand identity and context
    product-context.md                # Deep positioning reference (when created)
    sostac/                           # SOSTAC strategic planning phases
      README.md                       # SOSTAC overview and status tracker

    campaigns/                        # Named campaigns (Campaign → Channel → Deliverable)
      {YYYY-MM}-{type}-{campaign-slug}/   # e.g. 2026-03-launch-spring-release
        README.md                     # Campaign dashboard: Status:, Next:, key file links
        strategy.md                   # Campaign strategy doc
        content-plan/                 # Campaign content strategy, calendar, briefs
        channels/
          email/                      # Email content for this campaign
          social/                     # Social content for this campaign
          paid-ads/                   # Ad creatives for this campaign
          seo/                        # SEO deliverables for this campaign
          pr/                         # PR deliverables for this campaign
          blog/                       # Blog posts for this campaign
          video/                      # Video scripts for this campaign
          influencer/                 # Influencer briefs for this campaign
          website/                    # Landing-page and web copy for this campaign
        cro/  retention/  sales/  pricing/  community/
        guerrilla/  referral/  launch/  psychology/   # Campaign operational work
        analytics/                    # Campaign measurement
        performance/                  # Campaign performance reports

    channels/                         # Standalone/evergreen channel work (no campaign)
      email/  social/  seo/  video/  paid-ads/  pr/  influencer/
      blog/                           # Evergreen blog, case studies, whitepapers
      website/                        # Landing-page and web copy
      <channel>/performance/          # Channel performance reports stay inside the channel

    operations/                       # Standalone operational disciplines
      content-plan/                   # Content strategy, calendars, briefs
      cro/  retention/  sales/  pricing/  community/
      guerrilla/  referral/  launch/  psychology/

    analytics/                        # Brand-level analytics, measurement plans, reports
    dashboard/                        # Generated SvelteKit dashboard (paw-mkt-dashboard)
    assets/                           # Brand assets (logos, style guides, templates)
```

Channel and campaign folders hold their deliverables directly; there is no `content/` layer inside them. Campaign-scoped work always goes under `campaigns/{YYYY-MM}-{type}-{campaign-slug}/`; brand-level work goes to `channels/<channel>/`, `operations/<area>/` or `analytics/`.

## Campaign Folders

`{YYYY-MM}` is the campaign's start month (`YYYY-MM-DD` when several start in one month), so campaigns sort by time. Type prefixes: `launch`, `evergreen`, `seasonal`, `promotion`, `awareness`, `growth`, `retention`, `event`.

## Item READMEs

Every brand and campaign folder has a `README.md`: `# <Title>`, then `Status: <one phrase>` and `Next: <one step>`, then a short list of key files as relative links. The skill that creates the folder writes it; a skill that finishes a deliverable updates `Status`, `Next` and the list, then runs `uv run {skill-root}/scripts/paw-paths.py index` to refresh `{suite-root}/README.md`.

## Quick Reference: All File Paths

All paths are relative to `{suite-root}`.

```
brands/                                                         # All brands
brands/{slug}/README.md                                         # Brand dashboard
brands/{slug}/brand-context.md                                  # Brand identity and context
brands/{slug}/product-context.md                                # Deep positioning reference
brands/{slug}/sostac/README.md                                  # SOSTAC status tracker
brands/{slug}/sostac/01-situation.md                            # Situation Analysis
brands/{slug}/sostac/02-objectives.md                           # Objectives
brands/{slug}/sostac/03-strategy.md                             # Strategy
brands/{slug}/sostac/04-tactics.md                              # Tactics
brands/{slug}/sostac/05-action.md                               # Action Plan
brands/{slug}/sostac/06-control.md                              # Control & Measurement
brands/{slug}/campaigns/{YYYY-MM}-{type}-{campaign-slug}/       # Named campaigns
brands/{slug}/campaigns/{campaign}/README.md                    # Campaign dashboard
brands/{slug}/campaigns/{campaign}/strategy.md                  # Campaign strategy
brands/{slug}/campaigns/{campaign}/channels/{ch}/               # Campaign channel content
brands/{slug}/campaigns/{campaign}/{discipline}/                # Campaign operational work
brands/{slug}/campaigns/{campaign}/performance/                 # Campaign performance
brands/{slug}/channels/{channel}/                               # Standalone channel content
brands/{slug}/operations/{discipline}/                          # Standalone operational work
brands/{slug}/analytics/                                        # Reports and metrics
brands/{slug}/assets/                                           # Brand assets and templates
```
